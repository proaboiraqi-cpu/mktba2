AK Software - الإصدار 2
=======================
التشغيل (ويندوز):
  1) فك الضغط في أي مجلد.
  2) اضغط مرتين على start.bat  (أو في PowerShell اكتب:  .\start.bat )
  3) يفتح المتصفح على http://localhost:8000 ، وخلّي نافذة start.bat مفتوحة.
  يحتاج Python أو Node.js.

كل شي داخل المجلد (OpenCV و OCR العربي و PDF)، فيشتغل بدون إنترنت، والصور ما تنرفع لأي مكان.

الاستخدام: اختر الصور -> انتظر الكشف والتعرف -> راجع النوع (⚠ يعني تخمين) -> رتّب المستمسكات تلقائياً -> نزّل PDF.
- المستمسكات اللي بنفس الصورة تنفصل تلقائياً، وكل واحد ينقص وينعدل ميلانه.
- «أضف الصورة كاملة» بقسم الصور الأصلية إذا مستمسك فاته الكشف.
- الظهر ينربط تلقائياً بالوجه اللي قبله. للباقي: اكتب نفس الاسم أو علّم «نفس الشخص اللي قبله».
- إذا الأداة فشلت، يظهر سطر «أداة القص» أعلى الصفحة بسبب الفشل، أرسله لي.
